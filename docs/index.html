Benchmark anatomy

这套基准由什么构成

数据、规则与异常均为固定种子生成；干净数据单独执行，用于验证零误报。

规则构成

异常分布

01 / COMPILE

受限 DSL，而不是自由 SQL

表、列、操作符和参数均经过白名单校验；字符串字面量统一转义。抽取层和执行层解耦，避免模型直接接触数据库。

02 / EXECUTE

DuckDB 内存执行

7 个 SDTM 风格 CSV 以只读视图加载，规则编译后逐条执行，返回受试者级异常与字段证据。

03 / EVALUATE

注入异常 + 零误报检查

每个方案注入 34 条已知异常，按 (subject_id, rule_id) 计算 P/R/F1 与分类型召回；clean 数据必须零检出。
